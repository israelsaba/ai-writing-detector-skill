# Contributing

Contributions are welcome through pull requests. Preserve the skill entry point and rule references, explain the editorial benefit, and include focused tests or examples for rule changes. Discuss larger changes in an issue first.

Issues should include the version or commit, language, a minimal redacted example, expected behavior, actual behavior, and the relevant rule. Never post confidential drafts or private data.

Security reports belong in [SECURITY.md](SECURITY.md), not public issues.
